# 🎬 Sistema Web de Controle de Cinema | Cinema Management Web System

---

## 🇧🇷 Português

### 📌 Descrição

Este projeto é um sistema web desenvolvido com **HTML, Bootstrap e JavaScript puro**, que simula o gerenciamento de um cinema.

A aplicação permite cadastrar filmes, salas e sessões, além de realizar a venda de ingressos e visualizar as sessões disponíveis. Todos os dados são armazenados localmente utilizando **localStorage**, sem necessidade de banco de dados.

---

### 🚀 Funcionalidades

* 🎥 Cadastro de filmes
* 🏢 Cadastro de salas
* 🎬 Cadastro de sessões
* 🎟️ Venda de ingressos
* 📋 Listagem de sessões disponíveis

---

### 💻 Tecnologias Utilizadas

* HTML5
* Bootstrap 5
* JavaScript (puro)
* localStorage

---

### ⚙️ Como Executar

1. Clone o repositório:

```
git clone https://github.com/peedrolcs/CinemaMovieTime.git
```

2. Abra a pasta do projeto

3. Execute:

```
index.html
```

---

### 🧠 Conceitos Aplicados

* Manipulação do DOM
* localStorage
* JSON (JSON.stringify e JSON.parse)
* Criação dinâmica de elementos
* Integração entre páginas

---

📚 Objetivo

Este projeto foi desenvolvido com fins acadêmicos, com o objetivo de praticar conceitos fundamentais de desenvolvimento web front-end e manipulação de dados sem backend.

---

### ⚠️ Observações

* Os dados ficam armazenados no navegador
* Limpar o cache apaga os dados
* Não armazenar informações sensíveis

## 🇺🇸 English

### 📌 Description

This project is a web application developed using **HTML, Bootstrap, and pure JavaScript**, designed to simulate a cinema management system.

The application allows users to register movies, theaters, and sessions, as well as sell tickets and view available sessions. All data is stored locally using **localStorage**, with no need for an external database.

---

### 🚀 Features

* 🎥 Movie registration
* 🏢 Theater (rooms) registration
* 🎬 Session scheduling
* 🎟️ Ticket sales
* 📋 Available sessions listing

---

### 💻 Technologies Used

* HTML5
* Bootstrap 5
* JavaScript (Vanilla JS)
* localStorage

---

### ⚙️ How to Run

1. Clone the repository:

```
git clone https://github.com/peedrolcs/CinemaMovieTime.git
```

2. Open the project folder

3. Run:

```
index.html
```

---

### 🧠 Concepts Applied

* DOM manipulation
* localStorage usage
* JSON (JSON.stringify and JSON.parse)
* Dynamic element creation
* Multi-page integration

---

📚 Purpose

This project was developed for academic purposes, aiming to practice fundamental front-end web development concepts and data handling without a backend.

---

### ⚠️ Notes

* Data is stored in the browser
* Clearing cache will erase data
* Do not store sensitive information
